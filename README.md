# QiblaAstro iOS

Apple/iOS release workspace for QiblaAstro.

`WebApp/` is the frozen iOS baseline materialized from the authoritative QiblaAstro Android/Web release repository at the SHA recorded in `.ios-baseline-source-sha`.

Android-specific Bubblewrap/TWA packaging is deliberately not copied. iOS-native work must be added separately and must respect `IOS_PORT_CONTRACT.md`.
